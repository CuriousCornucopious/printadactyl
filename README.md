# Printadactyl 🦕

**Your ideas, printed.**

A 3D print commission marketplace — Designers post specs, Makers bid, everyone wins.

---

## The Idea

Got a 3D model? Need it printed? Post your specs, let makers compete for the job. No shop required.

- **Designers**: Have models, no printer → Post a request
- **Makers**: Have printers, need work → Bid on jobs
- **Platform**: Connects them, takes a commission

---

## How It Works

1. **Post** — Designer uploads STL/OBJ, specifies material, size, deadline
2. **Bid** — Makers see the request and submit their offers
3. **Print** — Designer picks a maker, they print and ship
